Weather Assistant

LLM-powered weather assistant built on top of Weather API. Combines deterministic advice rules (umbrella, clothing, watering) with a tool-calling agent, SSE streaming chat with persistent sessions and history, activity scoring, and best-day ranking. Includes 313 offline tests and an LLM evaluation suite measuring tool selection and groundedness.

Weather API Wrapper

REST API in Python (FastAPI) that wraps the Visual Crossing weather service and exposes current weather, forecast, and history through a stable, versioned contract. Features Redis caching with per-datatype TTL, IP rate limiting, Pydantic validation, and 26 tests that run without network or Redis. Docker Compose spins up the API and Redis with a single command.

Agentic Multi-Source RAG

Engineered an intelligent conversational assistant using Agentic RAG architecture. Integrated vector (ChromaDB/FAISS), tabular, and graph databases to enable multi-source information retrieval, serving responses through lightweight LLMs via REST APIs.

Data Warehousing & Business Intelligence

Designed and built an end-to-end ETL pipeline using MS Visual Studio (SSIS) to ingest and transform relational data into a Data Warehouse (MS SQL Server), developing interactive analytical dashboards in Power BI for decision-making.

Solar Energy Forecasting (Machine Learning & MLOps)

Developed and deployed a time-series forecasting model for solar power generation based on meteorological data. Handled feature engineering and hyperparameter tuning using Scikit-Learn/Pandas, productizing the solution via a real-time Streamlit web app.

Computer Vision & Facial Recognition

Developed real-time computer vision applications utilizing OpenCV and Deep Learning architectures (CNNs/Transfer Learning) for face detection, dog breed classification, and feature extraction.

Dog Breed Recognition System

Complete Computer Vision pipeline integrating embedding extraction, similarity search, supervised classification, and object detection to identify dog breeds in images. Features a Gradio frontend, async FastAPI backend, and Docker Compose deployment.

AgroVision-Edge | Crop vs Weed Detection

Edge-ready computer vision system using YOLOv8n to distinguish crops from weeds with mAP50=0.904. Optimized for on-device inference via ONNX export and INT8 quantization, cutting model size by 42% (6.25 → 3.60 MB) with only 1.84 mAP points lost. Includes CLI and an interactive Streamlit demo.

Agricultural Yield Forecasting

Prediction of agricultural yield (kg/ha) by province and campaign in Argentina, combining historical crop statistics from the Ministry of Agriculture (SIIA) with NASA POWER climate data. Daily weather is aggregated into phenological phases for soybeans, using a reusable pipeline designed to scale to other crops.
